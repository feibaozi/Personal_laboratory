# 🌐 数据获取备选方案指南

由于美团/饿了么等平台的商业API对个人开发者较难申请，我们准备了多种备选方案来获取数据。

---

## 📋 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **种子数据** | 即时可用，无需额外配置 | 数据量有限，可能不是最新 | ⭐⭐⭐⭐⭐ |
| **Playwright 爬虫** | 自动获取，数据较全 | 可能触发反爬，需谨慎使用 | ⭐⭐⭐⭐ |
| **用户手动录入** | 灵活、完全合规 | 需要用户操作 | ⭐⭐⭐ |
| **OCR 截图识别** | 直观、精准 | 需要截图 | ⭐⭐⭐ |
| **开放平台 API** | 官方支持，数据准确 | 个人开发者难申请 | ⭐⭐ |

---

## 🕷️ 方案 2: Playwright 爬虫（自动抓取）

### 特点
- ✅ 自动解析公开页面
- ✅ 无需API权限
- ⚠️ 需注意反爬机制
- ⚠️ 仅用于个人学习

### 代码结构

爬虫核心已在 [`app/collectors/meituan_collector.py`](../backend/app/collectors/meituan_collector.py) 实现：

```
MeituanCollector
├── collect_shop_menu(shop_url)
│   ├── _page_request()  - 请求页面
│   ├── _parse_page()    - 解析HTML
│   ├── _parse_shop_info() - 提取店铺信息
│   ├── _parse_products()  - 提取菜品
│   ├── _parse_delivery()  - 提取配送信息
│   └── _parse_coupons()   - 提取优惠券
└── _make_fallback_result() - 失败降级
```

### 使用流程

1. **用户分享店铺链接**
   ```
   例如: https://i.meituan.com/shop/123456
   ```

2. **系统自动解析**
   ```python
   result = await collector.collect_shop_menu(shop_url)
   ```

3. **数据入库**

### 测试爬虫

```bash
cd backend
python test_fallback_methods.py
```

## 🔤 方案 3: OCR 截图识别（可视化）

### 特点
- ✅ 直观易用
- ✅ 精准识别价格
- ⚠️ 需要截图

### 接口说明

**OCR 接口**: `POST /api/ocr/extract`

```json
{
  "images": ["base64_encoded_image"],
  "type": "menu"
}
```

### 使用场景

1. 用户在外卖APP截图店铺菜单
2. 上传截图到应用
3. OCR自动识别菜品名称和价格
4. 数据入库
